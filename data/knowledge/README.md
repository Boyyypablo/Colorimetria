# Base de conhecimento Colometria

Cards e rubrica **nossos** (paráfrase estruturada). Não são transcrição nem republicação do material de terceiros.

| Arquivo | Função |
|---------|--------|
| `rubric.ts` | Metodologia de avaliação (eixos + checklist) |
| `cards.ts` | Orientações por eixo, estação e objetivo |

Insumos brutos (vídeo, PDF, Whisper) ficam em `aprendizado/material/_extracted/` e **não entram no Git**.

Prioridade de destilação: módulos MakeUp Academy **04–09** (visagismo + colorimetria).

Para transcrever aulas no PC (sem API paga):

```bash
npm run knowledge:transcribe
```
